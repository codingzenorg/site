# CodingZen Flow website assets

Selected approved delivery exports from `codingzenorg/codingzen-assets`,
`logos/codingzen-flow/v1`, release 1.0.0 (CZ-1), published here for CZ-2.
The canonical repository is private; website assets are served locally.

The wordmark, favicon SVG/ICO, touch icon and combined PNG preserve the
approved outlined lettering, geometry, clear space and flat palette.
`social-preview.png` places the unmodified combined PNG on a 1200 × 630
ink (#101B15) background with the shared descriptor in off-white (#FAF9F6).
The descriptor uses DejaVu Sans; the logo lettering remains outlined artwork.
These files do not add a redistribution license for the CodingZen identity.

The build copies this directory to `dist/images/brand/` for stable social
preview URLs and staged game wrappers, alongside Vite's hashed shell assets.
